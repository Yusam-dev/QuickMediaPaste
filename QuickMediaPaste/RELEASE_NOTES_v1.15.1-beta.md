## QuickMediaPaste v1.15.1 (beta)

Paste images, video, audio, links, colors and text straight onto the Premiere Pro timeline.

**Tested:** Premiere Pro 25.1, Windows. **Untested:** macOS, other Premiere versions.

### Install
1. Close Premiere Pro.
2. Download `QuickMediaPaste_v1_15_1.zip`, unzip it.
3. Run `install-windows.bat` (or `install-mac.command`).
4. Open Premiere Pro > Window > Extensions > QuickMediaPaste.

The installer turns on CEP debug mode (the extension is unsigned). The uninstall script can turn it off again.

### Highlights
- Faster pastes (cached bin index, instant copy of big files, prepare-on-copy).
- Files and bins sorted by type.
- Editable text titles with your own `.mogrt` template (optional).
- Crash trace and detailed timing line to make bug reports easy.

### Reporting a bug
Use the Bug report template and paste the log (Show details > Copy log).
